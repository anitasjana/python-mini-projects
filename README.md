# Python Mini Projects

A collection of small Python projects for practice and learning.

## Projects

### 1. Contact Book

A console-based Contact Book application that saves data in a JSON file.

**Technologies used:**

- Python
- JSON
- File handling
- Exception handling
- Functions
- List of dictionaries

**Features:**

- Show all contacts
- Add a new contact
- Search a contact by name
- Update a contact's phone number
- Delete a contact
- Save contacts in a JSON file
- Handle missing, empty, or corrupted JSON files

**Folder:** `contact-book/`

**Run:**

```bash
python contact-book/contact_book.py
```

### 2. Student Management

A console-based program to manage student records using Python functions and a list of dictionaries.

**Technologies used:**

- Python
- Functions
- Loops
- List of dictionaries
- String formatting

**Features:**

- Add students
- Show all students
- Find the topper
- Calculate average marks

**Folder:** `student-management/`

**Run:**

```bash
python student-management/student_management.py
```

### 3. Number Guessing Game

A simple console-based number guessing game.

**Technologies used:**

- Python
- `random` module
- `while` loop
- Exception handling
- Functions

**Features:**

- Generate a random number between 1 and 100
- Take user guesses
- Show “Too high!” or “Too low!” hints
- Count the number of attempts
- Handle invalid input

**Folder:** `number-guessing-game/`

**Run:**

```bash
python number-guessing-game/number_guessing_game.py
```
